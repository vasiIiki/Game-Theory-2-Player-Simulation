# Game-Theory-Simulation - EIC-Project
# 2-Player Game Theory Simulation

## Description
This script is a simple implementation of fundamental Game Theory concepts using Python. Specifically, it begins by generating two random 2×2 payoff matrices - one for each player - representing the rewards they receive for every combination of strategies. Next, using a function, it determines the best responses for both players, identifying which strategies yield the highest payoff in response to the opponent’s choices. With this information, it finds any Nash Equilibrium points in the game. These equilibria are then displayed and visualised using a scatter plot. Moreover, this script checks and displays whether there are any Pareto Efficient outcomes and if the game is a Zero Sum one.

## Python libraries used
- numpy
- matplotlib
